我发现了问题的根源：当前的实现中，全局快捷键只在 Rust 端注册，但没有正确的事件处理机制。在 Tauri v2 中，需要直接在 Rust 端处理快捷键回调。

## 修复计划：

1. **修改 Rust 端实现**
   - 在 `lib.rs` 中，为 CapsLock 快捷键添加直接的事件处理回调
   - 移除前端的事件监听逻辑，因为快捷键处理应该在 Rust 端完成
   - 确保回调函数能正确创建命令窗口

2. **简化前端代码**
   - 移除 `+layout.svelte` 中的全局快捷键事件监听
   - 保持 `global-shortcut.ts` 中的 `openCommandWindow` 函数不变

3. **测试验证**
   - 重新启动开发服务器
   - 测试 CapsLock 按键是否能正确打开命令窗口

这个修复将确保 CapsLock 按键能立即在 Rust 端被捕获并触发命令窗口的创建。
