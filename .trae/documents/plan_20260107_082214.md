## 优化方案：根据启动参数决定显示哪个窗口

### 问题分析
当前方案：
- `tauri.conf.json` 中预定义了主窗口，应用启动时自动创建
- 通过 `COMMAND_MODE` 环境变量隐藏主窗口，再创建命令窗口
- **缺点**：主窗口被创建后又隐藏，浪费资源

### 优化后的方案
使用命令行参数（如 `--command`）来决定创建哪个窗口，完全避免创建不需要的窗口。

### 实现步骤

1. **修改 `tauri.conf.json`**
   - 移除 `windows` 配置，让窗口完全由代码控制

2. **修改 `lib.rs`**
   - 移除 `COMMAND_MODE` 环境变量检查
   - 添加命令行参数解析逻辑
   - 根据 `--command` 参数决定：
     - **无参数**：只创建主窗口（`main`）
     - **有 `--command` 参数**：只创建命令窗口（`command`）
   - 修改单实例插件的参数处理逻辑，支持 `--command` 参数

3. **添加新的命令窗口路由**
   - 在前端添加 `/command` 路由（如果还没有）

### 使用方式
```bash
# 正常启动，显示主窗口
ours-hotkey

# 命令模式，只显示命令窗口
ours-hotkey --command
```
