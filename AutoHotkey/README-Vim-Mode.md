# Vim Mode for AutoHotkey

这个脚本实现了基本的 Vim 编辑器操作模式，适用于 Windows 环境中的文本编辑。

## 功能特性

### 三种模式
1. **普通模式 (Normal)** - 默认模式，用于导航和删除操作
2. **可视模式 (Visual)** - 用于选择文本
3. **插入模式 (Insert)** - 用于输入文本

## 技术实现

脚本使用以下 AutoHotkey v2.0 特性：

- **条件热键**：使用 `#HotIf` 根据当前模式启用不同的热键集
- **双键检测**：通过时间戳比较实现 Vim 风格的双键操作（如 `dd`）
- **内置变量处理**：将内置变量赋值给局部变量以避免编译器警告
- **定时器回调**：使用命名函数处理异步操作
- **全局状态管理**：使用全局变量维护 Vim 模式状态

### 支持的操作

#### 普通模式
- `h` - 向左移动光标
- `j` - 向下移动光标
- `k` - 向上移动光标
- `l` - 向右移动光标
- `x` - 删除当前字符
- `X` (大写) - 删除前一个字符
- `d` + `d` - 删除整行（快速双击d键）
- `y` + `y` - 复制整行（快速双击y键）
- `u` - 撤销
- `Ctrl+R` - 重做
- `i` - 进入插入模式
- `v` - 进入可视模式
- `Ctrl+A` - 进入行可视模式

#### 可视模式
- `h/j/k/l` - 移动并扩展选择区域
- `x` 或 `d` - 删除选中的内容
- `ESC` - 返回普通模式

#### 插入模式
- 正常输入文本
- `ESC` - 返回普通模式

#### 全局操作（所有模式）
- `Ctrl+C` - 复制
- `Ctrl+V` - 粘贴
- `Ctrl+X` - 剪切
- `Ctrl+Z` - 撤销
- `Ctrl+Y` - 重做

## 使用方法

1. 运行 `ours-key.ahk` 主脚本
2. 脚本启动后会自动进入普通模式
3. 屏幕右上角会显示当前模式状态
4. 按 `F12` 查看操作说明

## 双键操作说明

脚本支持 Vim 风格的双键操作（如 `dd` 删除整行，`yy` 复制整行）：

1. **快速双击**: 在 500 毫秒内按两次相同键执行特殊操作
2. **单次按键**: 如果只按一次键，会在延迟后发送普通字符
3. **延迟时间**: 当前设置为 500ms，可根据需要调整

## 注意事项

1. **应用兼容性**: 该脚本在大多数文本编辑器中都能正常工作，但在某些特殊应用中可能表现不一致
2. **模式指示器**: 当前使用工具提示显示模式，后续可以优化为状态栏显示
3. **光标位置**: 在某些应用中光标位置检测可能不准确
4. **组合键**: 避免与其他全局热键冲突
5. **双键延迟**: 双键操作有 500ms 延迟，可能影响快速输入体验

## 故障排除

如果遇到问题：
1. 确保使用 AutoHotkey v2.0
2. 检查是否有其他脚本冲突
3. 查看脚本运行日志
4. 按 `F12` 查看当前状态
5. 如果遇到语法错误，确保所有回调函数都使用命名函数而不是箭头函数
6. 对于内置变量警告，在函数中使用 `global A_CaretX, A_CaretY` 等声明
7. 确保从 AutoHotkey 目录运行主脚本，以正确解析包含文件路径
